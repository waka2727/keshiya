# Economy Rebalance — DRAFT / 0.9候補

今回は報酬・商品価格・消しカス価格・スキル倍率を変更しない。高級製図消し50,000円も維持する。

実データはCurrentData.mdに再生成する。消去面積はマスクの非ゼロ面積であり、所要時間の実測ではない。Protected密度だけでは細部の近接性を表せない。★の改定には接触形状で安全に処理可能な面積と実プレイを併用する。

候補：通常依頼報酬を下げる／消しカス収入の相対価値を上げる／高級製図消しを長期目標化／詰み防止の無料・無限備品消しゴム。

いずれも未採用。先に複数テスターの購入履歴、1本の使用件数、摩耗による買い替え費用、依頼と消しカスの収入割合を集める。平均報酬だけで価格を一律に上げない。初見の選択自由と長期目標を両立する。

referenceSecondsは依頼ごとの固定値で、Job.Completeの追加スピードボーナスに使われる。0.8.2では不正確な目安表示だけを削除し、時間の計算と報酬式は維持した。遅くても基本報酬は減らない。
