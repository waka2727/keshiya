# Story Bible — 確定事項と検討事項

本書は作者の2026-10-02時点の指示を整理した設計資料。新しいシナリオをRuntimeへ登録するものではない。

## 作者が示した確定方針

中心テーマは「何を消すかより、何を残すか。」。

主人公は以前から「消し屋はなくならない職業」という話を聞き、なんとなく興味を持っていた。ある日、年配の男性の消し屋と偶然出会い、突然店を任される。最初から強い使命感がある人物ではなく、仕事を続けるなかで消すことの責任や重みを理解する。

舞台は地方都市、住宅街に近い高架下の静かな小さな消し屋。依頼は郵送のみで、依頼人とは直接会わない。依頼文・依頼品・完了後の文章が人物像を伝える。消し屋はこの町では普通の職業として扱い、存在理由を長々と説明しない。

物語全体は約2年間。Day 1等のカウントを前面に出さず、季節、依頼内容、手紙、再登場から経過を感じさせる。

トーンは日常7割、人情2割、少し妙1割。超常的な消しカスの価値、ホラーの買取人、世界の危機等は追加しない。

## 世界ルールとして確定している範囲

消し屋が正式な書類等から消した内容は、現実の「正式な事実」に影響することがある。答案の100点から10を消すと正式な点数も0点になる例がある。

人間の記憶・感情・経験・身についた能力まで消えるわけではない。「好きだ」という文字を消しても、恋心そのものは消えない。

このルールから、契約や戸籍等の処理まで類推して確定しない。詳細はOpenWorldRules.mdで保留する。

## 候補・未確定

常連は3〜4人程度を想定。漫画家と恋愛関係の依頼人が候補。「誰にも見せない名前」の依頼人が後の結婚式の招待状へつながる可能性はあるが、結婚の成立、同一人物の確定、登場順を決定したものではない。

主人公の氏名、過去、店を任された理由、年配男性のその後、結末は未決定。本基盤にはフラグ等の格納先だけを設け、イベント実装や解放条件を有効化しない。

## 制作上の境界

External Test 01の8依頼、文章、ゲームプレイを凍結。漫画家の誤字は表現であり修正しない。将来の文章案はDRAFTとして別ファイルへ置き、作者承認までゲームに登録しない。


## External Test 01の知見（0.8.2 / 設計原則）

依頼順には物語上の意味を持たせる。常連漫画家、名前入り消しゴムの依頼人、後の結婚関連候補、他の常連を点ではなく線で考える。ただし誰が結婚するか、どの依頼と同一人物か、登場順はDRAFT。今回Runtimeの順序・解放条件は変更しない。

「なぜわざわざ郵送するのか」という違和感は興味につながった。紙が貴重だから等の理由を確定しない。正式な事実への影響との関係を含め、謎を少しずつ感じる余地を残す。外部試遊版の歴史的アーカイブは不変。0.8.2の本文修正はTEST_001の猫への整合のみ、低品質反応は別追加として扱う。
