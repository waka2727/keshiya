# Open Questions / Rule Decision Log

以下はすべて **OPEN（作者未決定）**。技術実装や依頼案から回答を既成事実にしてはならない。

| ID | 論点 | 作者判断が必要な問い | 影響する制作 |
|---|---|---|---|
| RULE-01 | 原本とコピー | どちらが正式な事実へ作用するのか | 複写の依頼、保管 |
| RULE-02 | デジタル記録 | デジタル上の文字や紙への出力はどう扱うか | 印刷物、記録の依頼 |
| RULE-03 | 写真 | 写真の像と添え書きは同じ扱いか | 思い出の依頼 |
| RULE-04 | 複数原本 | 矛盾した原本の優先関係はあるか | 正式書類 |
| RULE-05 | 契約 | 一部消去が契約に何を起こすか | 中盤以降の責任 |
| RULE-06 | 戸籍 | 消去の適用範囲と禁止範囲はあるか | 本編の倫理的分岐 |
| RULE-07 | 婚姻届 | 公式の関係と感情の扱いはどう分かれるか | 恋愛常連の展開 |
| RULE-08 | 再記入 | 消した後の書き戻しが何を起こすか | 修正、やり直し |
| RULE-09 | 法的責任 | 誰が結果に責任を負うか | 店の規則、依頼受付 |
| RULE-10 | 拒否できる範囲 | 店主が断れる依頼や根拠は何か | 選択肢、結末 |
| RULE-11 | 仕組みの認知 | 誰が現実への作用を知っているか | 依頼人の語り口 |

## 決定ログの運用

作者承認時に、日付・決定文・承認の参照・影響依頼ID・旧記述を追記する。候補案の採用をコード変更だけで済ませない。未決定のままでもコンテンツデータは保持できるが、Runtime公開はしない。
