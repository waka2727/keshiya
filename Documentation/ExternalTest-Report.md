## 制作方法
Figma / CLIP STUDIO / Illustratorは使用していません。Pillow / NumPyによる組版・マスク生成と、画像生成で作成したオリジナルの3枚のイラスト原本を組み合わせました。ユーザーによる外部ソフト操作は不要です。

文章が重要な便箋、レシピ、答案はWindows日本語フォントによる文字単位の組版です。漫画は既存作品を参照しないオリジナルの人物・背景・5コマ完成線を画像原本とし、別工程で青灰色の下書きを加えています。子どもの落書き、美術学生の没ラフも保存済み原本から透過画像へ変換します。

生成コードは `Tools/ExternalArt/generate.py`、依頼文章は `job-001.json` ～ `job-008.json`、画像入力は同フォルダーの `*-original.png`、制作原本は `Tools/ExternalArt/Source/TEST_001` ～ `TEST_008`。固定した原本と乱数シードで再生成できます。TEST_002の7レイヤーは再生成前後でバイト単位の一致を確認しました。AI画像を新たに生成し直す工程自体の同一性を保証するものではありません。

## レイヤーと解像度
8件とも制作原本 **2480×3508**、Unity実使用 **1240×1754**。各依頼の全レイヤーは同じキャンバス・座標です。

| レイヤー | 役割 |
|---|---|
| Paper | 消えない紙・紙地・シミ・折れ・便箋の背景 |
| Protected | 残す文章・完成線・採点など |
| Erasable | 段階的に消える鉛筆画像 |
| EraseMask | 消去率と消去量の正式な重み |
| ProtectMask | 保護対象損傷の正式な重み |
| CompletePreview | 紙＋保護対象の完成状態 |
| InitialPreview | 依頼選択画面用の初期状態 |

PNGは `Assets/Keshiya/ExternalArt/TEST_00x/レイヤー名.png` にあります。Protectedがない依頼も、透明のProtectedと黒いProtectMaskを持ちます。画像を目測で合わせる操作はありません。

EraseMaskは独立したグレースケールの重みです。ゲーム中に表示色から黒鉛かどうか推測しません。ProtectMaskは元の保護アルファより1原本ピクセル内側の許容範囲を持ちます。漫画・レシピの完成線直下に隠れた消去目標を作らず、細い角が通る間隔を確保しました。

## Unity共通実装
- `JobArtworkData`：7画像、Worldサイズ、原本パス、manifestハッシュ、検証用走査座標。
- `ExternalArtworkImporter`：manifestを列挙し、TextureImporterとJobDefinitionを自動作成・更新。
- `Drawing`：EraseMaskから黒鉛残量を生成。筆記具の質量補正も維持。
- `ProtectedDrawing`：ProtectMaskから独立した保護残量を生成。
- `Paper`：既存の接触・損傷計算を再利用。現在の対象残量、保護残量、紙損傷を状態画像に出力。
- `LayeredPaper.shader`：紙・対象・保護をGPU合成。高解像度画像をCPUで毎回全合成しません。
- `WorkFlowHUD`：外部試遊8件フィルター、初期画像プレビュー、依頼文・成功文スクロール。
- `PrecisionViewport` / `PrecisionAssist`：ズーム・パン・完成見本。完成見本中は入力を遮断し、持ち物画面を往復しても維持します。
- `EraserPresentation`：支給品の残量に応じて高さを縮め、名前画像を削れた側から切り詰めます。接触判定サイズを名前画像に合わせて変更していません。

旧式の線データを使う20依頼も同じPaperクラスで引き続き動きます。8本の専用消去コードはありません。

## ズームと精密操作
ホイール／＋／－で1～4倍。カーソル位置の紙面座標を前後で保持するようカメラ中心を補正し、中ドラッグで移動、Homeで全体に戻ります。画面から紙平面へのRayでWorld座標を求め、その後共通UVへ変換します。面・辺・角のWorld接触サイズ、回転、性能倍率はズームに連動しません。

精密依頼ではHで完成状態を確認できます。消す線は青灰色、保護線は黒や濃い文字、採点は赤です。古い紙の既存損傷値も状態テクスチャへ渡し、局所的な亀裂・裂けの簡易表現へ接続しています。
