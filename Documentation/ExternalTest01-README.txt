【消し屋 External Test 01】

これは開発中の試遊版（Prototype）です。
UI・グラフィック・バランス・内容は今後変更されます。
30～60分程度、気になるところまで自由に遊んでください。
全部の依頼を遊ぶ必要はありません。

■ 起動
ZIPをすべて展開して、Keshiya.exe を起動してください。
exeだけを取り出さず、同じフォルダ内のファイル一式を残してください。
Unity Editorは不要です。終了はウインドウの×またはAlt＋F4です。

■ 最初の一歩
「最初の依頼を読む」から、作業中の短い操作ヒントを試せます。
「自由に依頼を選ぶ」から始めても構いません。
ヒントは閉じられます。F1のヘルプで再表示・スキップできます。
制限時間はありません。消去率95%以上で「依頼完了」を押せます。

■ 基本操作（作業画面）
マウス移動：消しゴムを動かす
左ボタンを押しながら移動：紙を擦る
Q／E、または面・辺・角ボタン：接触する部分の切替
R：45度回転 / Shift＋R：逆回転
Wheel：上下移動
Ctrl＋Wheel：カーソル付近を中心にズーム
中ボタンドラッグ：紙面を移動 / Home：全体表示
＋／－キー（テンキーも可）：ズームの代替操作
H：精密依頼の完成見本（同じスクロール・ズーム操作）
1～9：所持している種類へ切替 / Tab：次の個体
T：所持品・持ち込み選択
Space：消しカスを吹く / C：回収 / Z：吹いた直後の救済
G：細かいカスを玉にする / V：買取窓口
K：スキル / F：取得済みの消し残し感知
M：音のミュート
F1：ヘルプ・設定 / F2：FPS表示の切替

■ やり直し・進行
作業画面の「やり直す」は、確認後に現在の仕事の開始状態へ戻します。
その仕事で変化した道具状態や取引等も戻るため、報酬の重複取得はできません。
全進行を戻す場合は、F1 →「テストデータ初期化」→ 確認してください。
所持金・道具・スキルなどは起動中のみ保持します。終了すると次回は初期状態です。
初期状態：0円、普通／やわらか／砂消し各1本、スキルLv0、EXP/SPなし。
8依頼、ショップ、スキル、消しカス買取は自由に利用できます。

■ 不具合・感想
何をしていたか、依頼名、起きたことを教えてください。
可能ならスクリーンショットを添えてください。Feedback.txtも自由に使えます。
ログはPC内だけに保存され、自動送信されません。
記録内容：依頼・道具・操作モードの使用量、時間、損傷、評価、購入、スキル、FPS、エラー種別。
名前・IP・Windowsユーザー名・PC識別子・ローカルパス・生の例外文は記録しません。
保存先：Unity標準のユーザーデータ領域の「Keshiya Studio / 消し屋 External Test / ExternalTest01 / Logs」。
Windowsではユーザーフォルダ内 AppData/LocalLow 以下です。
ログを共有する場合は、必要なセッションの .log だけを選んでください。
テストデータ初期化後も調査用ログは残ります。
